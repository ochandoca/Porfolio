Ray Tracing in DirectX12

Resume

This project is an implementation of ray tracing using the DirectX 12 API, designed to explore and demonstrate modern graphics rendering techniques. The demo features lighting effects such as shadows and reflections, taking advantage of accelerated hardware to maximise performance.

Developed in C++ with SDL for window management and tools such as Premake5, Visual Studio and NVIDIA's Nsight.

Showcase

Demo Features

This demo provides a fully rendered scene with ray tracing, two points of light and multiple meshed objects, such as spheres and cubes, plus this demo contains a fly camera to observe the scene from various points.

Here is a list of the implemented features:

  • Lighting
    • Point Light
  • Shadows
  • Reflections

Lighting

This demo uses exclusively point lights because of their easy integration with rendering systems based on the Phong lighting model. Point lights emit light from a specific point in all directions, allowing light sources such as light bulbs or candles to be simulated efficiently. In this context, the Phong model is used to calculate both diffuse and specular lighting, achieving a balance between visual realism and computational performance. This choice simplifies the rendering pipeline while providing a sufficient graphical environment to demonstrate the capabilities of the implemented ray tracing system.

Shadows

The shadow calculation in this demo follows a straightforward but efficient approach. To determine whether an object is illuminated, a ray is cast from the object's position towards the light source. This beam, called a ‘shadow ray,’ checks if there is any intersection with another object between the point and the light.

  • Unobstructed case: If the ray does not encounter any obstacles in its path, the light is considered to hit the object directly. In this case, the contribution of diffuse and specular light is calculated and added to the Phong illumination model, generating a realistic appearance including bright reflections and soft shading depending on the material of the object and the position of the light.

  • Obstructed case: If the beam intercepts any object in the path, the light is determined to be blocked, and therefore no light contribution is added from that source. This mechanism simulates hard and sharp shadows, which are characteristic of point lights.
