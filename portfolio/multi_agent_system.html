Multi Agent System

Resume

This multi-agent system developed in Unity allows the simulation and coordination of agents with different roles within an environment. Each agent has a set of behaviours and decision making based on its assigned role.

Showcase

Main features

  • Different Agent Roles: Each agent has a specific task within the system, which allows for a structured and cooperative organisation in the simulation.
  • Sight-Based Perception System: Agents detect objects and other agents within their field of vision and react accordingly.

This agent system is mainly based on three types of agents, which are able to move in the environment without interacting with each other.

  • Explorers: They are in charge of scouring the environment for minerals and possible threats.
  • Miners: When an explorer detects an ore, one of the available miners is automatically assigned to extract it.
  • Knights: If a scout detects an enemy, a signal is sent out for knights to come to the area and attack it.

The tasks of the agents within this system are assigned by means of a message system and a bidding system. There is a mailbox where messages are left and the agents will bid for them. However, each agent still has control over its status. This allows the agent to make decisions that have nothing to do with the message.
